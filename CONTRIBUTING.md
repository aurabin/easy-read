# Mitmachen — Easy Read

Jeder kann hier mitmachen.
Du brauchst kein Team.
Du brauchst keine Kamera.
Alles läuft schriftlich.

## drei Wege

### 1. Fehler melden

Du hast etwas kaputt gesehen?
Schreib ein Issue auf GitHub:
https://github.com/aurabin/easy-read/issues/new/choose

Sag:
- was du gesehen hast,
- was du erwartet hast,
- auf welcher Seite es war.

Ein Satz pro Punkt reicht.

### 2. Text verbessern

Unsere Texte sind auf Deutsch.
Manche sind auf Englisch.
Wir haben sechs Sprachen im Witz.

Du kannst:
- einen Satz kürzen,
- ein hartes Wort erklären,
- eine Übersetzung schicken,
- eine Lektion schreiben.

Regeln:
- kurze Sätze, höchstens zwölf Wörter,
- alltägliche Wörter,
- ein Gedanke pro Absatz,
- keine Belehrung, kein Spott.

Der Prüfer hilft:
`node .opencode/skills/easy-read/scripts/readability.mjs --lang de DATEI`

Ziel ist 100 von 100 Punkten.

### 3. Code und Bilder

Du kannst:
- eine Demo bauen,
- ein Bild zeichnen,
- ein Programm für KolibriOS schreiben,
- eine Prüfung ergänzen.

Regeln:
- kein WAV im Build,
- `docs/` nie direkt bearbeiten,
- nach Änderungen `node field-generator/build-docs.mjs` laufen lassen,
- `node tools/self-engineer.mjs` muss OK sagen.

## So schickst du es

1. Forke das Repository.
2. Mach einen Branch.
3. Mach einen Commit.
4. Öffne einen Pull Request.

Oder schreib ein Issue mit deinem Text.
Wir lesen alles.

Deine Meinung zählt zuerst.
Schreib uns. Kein Video, kein Anruf.

## English, short

Everyone can help. Write only. No camera, no calls.
Open an issue, send a pull request, or improve a text.
Short sentences. Kind words. No claims of "accessible".
