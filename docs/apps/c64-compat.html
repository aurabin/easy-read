BASIC 2.0 — BEFEHLE
BefehlBedeutung
PRINTSchreibt Text auf den Bildschirm
GOTOSpringt zu einer Zeilennummer
LETGibt einer Variablen einen Wert
IF ... THENEntscheidung
FOR ... NEXTWiederholung
INPUTFragt nach einer Eingabe
CLRLöscht Variablen
NEWLöscht das Programm
ENDHält das Programm an

Diese kleine BASIC-Umsetzung unterstützt PRINT, GOTO, LET, IF/THEN, FOR/NEXT und END. Teletext-Farben gehen mit dem Zeichen {c} (cyan), {r} (rot), {g} (grün), {w} (weiß).
