# Learn

## First, a joke

„Mir reichts! Ich geh schaukeln! Meine Freunde gehen rutschen!“

“I’ve had enough! I’m off to the swings! My friends are off to the slide!”

The pun is German. All six languages are in [`joke.md`](joke.md).

Three ways to use this folder.

1. **No experience?** Start with `start-here/`. Four lessons. They assume
   nothing.
2. **A course.** Start with the Commodore 64, then the Amiga. Twelve short
   lessons. No old hardware needed.
3. **One lesson.** Jump to the topic you want.
4. **The big picture.** Read
   [`computer-history.md`](computer-history.md). From Zuse to AI.
5. **One famous chip.** The illustrated course in [`chips/`](chips/README.md).

## How a lesson works

- One idea per section.
- Short sentences. Numbers for steps.
- "What you should see" after the steps.
- "If it does not work" with one fix per line.
- A 5-minute task at the end.
- One question you can ask the agent.

## Ask the agent

Open the project in OpenCode. Type:

```text
/learn explain step 3 of the C64 lesson 2
```

The agent answers in Easy Read, in your language.

## Honest notes

- These lessons are not tested with the people they are for yet.
- Links, prices, and downloads change. Check before you download.
- Old software has copyright. Use free software, or files you own.
- You do not have to finish a course. One lesson counts.
