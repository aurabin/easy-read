# AI Coding Course for ALL Adults

AI is a tool that makes a draft. It is not an authority.
This course assumes no coding experience.
It also works if you have coded before.

## What you will learn

1. What AI does, and where it fails.
2. How to write a prompt you can check.
3. How to read and change the demo code.
4. How to audit the full feature map.
5. How to revise, debug, and remove garbage.
6. How to build and test across environments.
7. How to maintain and publish.
8. How to earn money, honestly.

## Rules

- Do not put personal, client, or health data in a prompt.
- Check facts and code. Run it before you trust it.
- Keep the original file. Change a copy.
- You are responsible for what you publish.
