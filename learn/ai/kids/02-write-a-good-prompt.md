# Lesson 2: Write a good prompt

**Time:** 10 minutes. **You need:** lesson 1.

## Short answer

A prompt is your instruction to the AI.
A clear prompt has 4 parts.

## The 4 parts

1. **What:** the thing you want.
2. **Where:** the place or format. A web page, a picture, a list.
3. **How:** the size, colours, sounds, or style.
4. **Check:** ask the AI to say what it is not sure about.

## A weak prompt

```text
Make a game.
```

The AI must guess too much.

## A better prompt

```text
Make one web page with a small ball game.
The ball bounces inside a box.
Use red and white. Use a keyboard.
Do not use any files from the internet.
Say what you are not sure about.
```

## The example prompt

The example in this pack is short.
It asks for two things at once:
a virtual field generator, and a Boing Ball demo.

A person had to decide:

- the size of the page;
- the colours;
- how the ball moves;
- what "field" means.

That is normal. A short prompt is a start, not a full plan.

## Try this

Take the weak prompt "Make a game."
Add one part at a time: What, Where, How, Check.
Read the four versions out loud.

## Ask me

Ask the agent: "Which part is missing from my prompt?"
