# Lesson 4: The feature map

**Time:** 10 minutes. **You need:** lesson 3.

## Short answer

A feature is a thing a tool can do.
There are many AI features. There are many coding features.
You do not need all of them today.

## Two lists

- [`features/ai-features.md`](../features/ai-features.md) lists AI features.
- [`features/dev-features.md`](../features/dev-features.md) lists coding features.

Each row has a small task.
The status says if it is here, taught, or planned.

## Pick three

1. Pick one feature you know.
2. Pick one feature you do not know.
3. Pick one feature you want to try.

Read the row. Do the smallest step.
Say what happened.

## A rule

A list is not a promise.
Some things work here. Some are lessons. Some are only plans.
Say which is which.

## Try this

Pick these three rows:

1. Alt text.
2. Keyboard access.
3. Unit test.

Do one step from each row. It can take 2 minutes.

## Ask me

Ask the agent: "Which feature should I learn next, and why?"
