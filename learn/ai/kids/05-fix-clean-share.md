# Lesson 5: Fix it, clean it, build it, share it

**Time:** 15 minutes. **You need:** lesson 3. The demo file.

## Short answer

A project has a path.
It starts as a draft. It ends as something you share.
The path has five steps.

## The five steps

1. **Revise.** Change one thing.
2. **Debug.** Find why it broke.
3. **Clean.** Remove what you do not need.
4. **Build.** Make the file you will share.
5. **Test in two places.** A second browser or screen size.

## Revise

Change one thing. Then stop.
Look at the diff. A diff shows what changed.
If it is wrong, go back. That is called rollback.

## Debug

A bug is a mistake in the code.
Do not guess. Find the smallest case that fails.
Read the error. Say it out loud.
Change one line. Test again.

## Clean

Garbage in a project is:

- code nobody uses;
- files nobody opens;
- old copies of the same picture;
- build output and logs.

Move it out. Test again.
If nothing breaks, delete it later.
Keep a copy first.

## Build

A build turns source files into the thing you share.
For the demo, the build is already done.
It is one HTML file. It needs no server.

## Test in two places

Open the file in two browsers.
Try a small screen. Try a big one.
Try the keyboard. Try "Less motion".

## Money

You can earn money from work you make.
Here are four ways:

- **Sell it.** A person pays for the file or the app.
- **Teach it.** A person pays for a lesson or a workshop.
- **Fix it.** A person pays you to repair or improve their project.
- **Ask for support.** People can pay a little each month.

Always say the price before you start.
Ask an adult about money, tax, and bills.
