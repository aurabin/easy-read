# 中国计算机简史

这是我们的计算机历史长篇。用简短的句子写成。
中文版还在建设中。这一版是初稿。
还没有真正的用户测试过。

## 一、最早的想法

很久以前，人们就想让机器自己算数。

| 年份 | 发生了什么 |
| --- | --- |
| 1837 | 巴贝奇设计了分析机。它没有造成。 |
| 1843 | 阿达写了第一个程序。 |
| 1936 | 图灵描述了通用机器。 |

这些想法很重要。后来的计算机都用了它们。

## 二、第一台机器

| 年份 | 发生了什么 |
| --- | --- |
| 1941 | 楚泽造了 Z3。它在德国。 |
| 1945 | 冯·诺依曼写下了计算机的构造。 |
| 1946 | ENIAC 在美国公开。 |

当时的机器很大。它们用电子管。它们很热。
它们常常坏。

## 三、晶体管和芯片

| 年份 | 发生了什么 |
| --- | --- |
| 1947 | 晶体管造出来了。 |
| 1958 | 集成电路出现了。 |
| 1965 | 摩尔说，芯片上的元件会越来越多。 |

机器变小了。它们变便宜了。
后来，每个人都能有一台电脑。

## 四、微处理器和个人电脑

| 年份 | 发生了什么 |
| --- | --- |
| 1971 | 英特尔做出 4004。 |
| 1975 | Altair 8800 出现了。 |
| 1977 | Apple II、PET 2001 和 TRS-80 出现了。 |
| 1981 | IBM PC 出现了。 |
| 1982 | Commodore 64 出现了。 |

电脑走进了家庭。
很多人第一次学会了打字。
Commodore 64 用了 BASIC。
我们的课程也教这个。

## 五、网络

| 年份 | 发生了什么 |
| --- | --- |
| 1969 | ARPANET 发出第一条消息。 |
| 1983 | 网络改用 TCP/IP。 |
| 1989 | 万维网被提出。 |
| 1991 | 第一个网站上线。 |
| 1994 | 中国接入了互联网。 |

1994 年是中国互联网的开始。
从那以后，很多人开始上网。

## 六、中国的计算机发展

| 年份 | 发生了什么 |
| --- | --- |
| 1958 | 中国造出第一台电子计算机。 |
| 1965 | 109 丙型机完成了。 |
| 1983 | 银河一号巨型机研制成功。 |
| 1990 年代 | 个人电脑进入中国家庭。 |
| 2000 年代 | 互联网公司出现了。 |
| 2010 年代 | 手机上网很普遍。 |

这些年份来自公开资料。
有些细节还没有核实。
我们写“未核实”，不写猜测。

## 七、游戏和演示场景

| 年份 | 发生了什么 |
| --- | --- |
| 1972 | Pong 出现了。 |
| 1978 | 太空侵略者出现了。 |
| 1984 | Amiga 的弹跳球出现了。 |
| 1992 | State of the Art 赢得了比赛。 |

演示场景是一种艺术。
人们分享代码和图画。

它是我们自己画的。不是复制的。

## 八、人工智能

| 年份 | 发生了什么 |
| --- | --- |
| 1950 | 图灵提出了他的问题。 |
| 1956 | 达特茅斯会议给了这个名字。 |
| 2012 | AlexNet 让深度学习出名。 |
| 2016 | AlphaGo 赢了。 |
| 2022 | 人工智能成了大众产品。 |

人工智能会写草稿。
它不是人。它会出错。
检查事实后再用。

## 九、BOINC — 很多电脑一起算

BOINC 在 2002 年开始。
它把很多电脑连在一起。
志愿者把电脑借给科学研究。
David Anderson 领导了这个项目。
它从 SETI@home 开始。

这是自由软件。代码用 LGPL 许可。
我们不能确认吉尼斯纪录的说法。
所以这里不写它是事实。

## 十、开放和诚实
