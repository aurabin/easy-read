# 用简明中文学习

## 这是什么

这是一个练习。你可以用中文读简单的句子。
句子很短。词语很常见。
每一行只有一个意思。

## 练习一：电脑

电脑是一台机器。
它按照指令做事。
你告诉它做什么。
它就做什么。

## 练习二：程序

程序是一张清单。
电脑一行一行地读。
它做完一行，再做下一行。

## 练习三：仓库

仓库是电脑的一部分。
它记住东西。
关掉电脑后，东西还在。

## 练习四：网络

网络把电脑连在一起。
你可以发消息。
别人可以回消息。

## 试试看

1. 读一遍。
2. 画出你不认识的词。
3. 查意思。
4. 再读一遍。
5. 用三个词写一句话。

## 检查

我们的检查器现在支持中文。
用这个命令：

```sh
node .opencode/skills/easy-read/scripts/readability.mjs --lang zh DATEI.md
```

中文的特征和别的语言不同。
一句话最好不超过十八个字。
成语要换成简单的话。
难词要换成常用词。

## 诚实

中文不是经典的简易阅读语言。
这里的规则是我们自己定的。
没有官方的中文简易阅读标准。
我们还没有问过真正的用户。
如果你读到了困难的地方，请告诉我们。
