# Lektion 2 — Das HTML

## Die Idee

HTML gibt dem Text eine Rolle.
Eine Überschrift ist groß.
Ein Absatz ist klein.
Ein Link geht weiter.

## Ein Beispiel

```html
<h1>Meine Seite</h1>
<p>Ich baue gerade Code.</p>
<a href="https://aurabin.github.io/easy-read/">Zur Website</a>
```

## Die Schritte

1. Öffne deine Datei `hallo.html`.
2. Ersetze den Text zwischen `<body>` und `</body>` durch das Beispiel oben.
3. Speichere.
4. Lade die Seite neu.

## Das solltest du sehen

Eine große Zeile.
Eine kleine Zeile.
Einen blauen Link.

## Wenn es nicht geht

- Alles ist groß? Prüfe, ob `<h1>` und `</h1>` beide da sind.
- Der Link geht nicht? Prüfe die Adresse nach `href=`.

## Wörter

- **Tag** — ein Zeichen wie `<h1>`. Es beschreibt den Text.
- **Link** — ein Klick, der zu einer anderen Seite führt.

## Deine Übung

Schreibe drei Absätze.
Mach den zweiten Satz zu einer Überschrift.
