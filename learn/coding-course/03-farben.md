# Lektion 3 — Farben

## Die Idee

CSS bestimmt, wie die Seite aussieht.
Farben gehören dazu.
Eine Farbe hat einen Code.
Der Code beginnt mit einer Raute.

## Ein Beispiel

```html
<style>
body{background:#070b14;color:#eaf2ff}
h1{color:#6fd3ff}
</style>
```

## Die Schritte

1. Öffne deine Seite.
2. Schreibe das Beispiel zwischen `<head>` und `</head>`.
3. Fehlt der Kopf? Schreibe ihn dazu:

```html
<head><meta charset="utf-8"></head>
```

4. Speichere und lade neu.

## Das solltest du sehen

Einen dunklen Hintergrund.
Hellen Text.
Eine blaue Überschrift.

## Wenn es nicht geht

- Alles bleibt weiß? Prüfe, ob `<style>` richtig geschrieben ist.
- Der Text ist dunkel? Prüfe den Wert nach `color:`.

## Wörter

- **CSS** — die Sprache für das Aussehen.
- **Hintergrund** — die Fläche hinter dem Text.

## Deine Übung

Mach den Hintergrund grün.
Nutze `#070b14` als Vorbild.
Ändere nur die Zahlen und Buchstaben danach.

## Eine Frage an den Agenten

„Warum ist dunkler Grund mit hellem Text gut lesbar?"
