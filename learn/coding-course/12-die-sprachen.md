# Lektion 12 — Die anderen Sprachen

## Die Idee

Du kennst schon HTML, CSS und JavaScript.
Es gibt noch viele andere Sprachen.
Keine ist die beste.
Jede passt zu einer Aufgabe.

## Die Familien

| Familie | Sprachen | Wofür |
| --- | --- | --- |
| Alt und nah an der Maschine | C, C++, FASM, Zig, Rust | Systeme, Spiele |
| Leicht zu lesen | Python, Ruby, Lua, BASIC | Skripte, Spiele, Automatisierung |
| Im Web | JavaScript, TypeScript, PHP, Dart | Seiten, Apps, Server |
| Für Daten | SQL, R, Python, Julia | Tabellen, Statistik |
| Für Geräte | Swift, Kotlin, Java, C++ | Telefon, Fernseher, Auto |
| Für Ideen | Lisp, Prolog, Haskell, Erlang, Elixir | Forschung, Nebenläufigkeit |
| Für Lernende | Scratch, Python, BASIC | Der erste Schritt |

## Einige im Einzelnen

- **Python** — kurz und gut lesbar. Gut für Skripte.
- **C** — nah an der Hardware. Viele Systeme sind damit gebaut.
- **C++** — C mit mehr Möglichkeiten. Viele Spiele nutzen es.
- **Rust** — sicher und schnell. Ohne viele klassische Fehler.
- **Go** — einfach und gut für Server.
- **Swift** — für Apple-Geräte.
- **Kotlin** — für Android.
- **Java** — läuft auf vielen Geräten.
- **PHP** — viele Websites laufen damit.
- **Ruby** — angenehm zum Schreiben.
- **Lua** — klein. Viele Spiele nutzen es für Regeln.
- **SQL** — fragt Daten aus Tabellen ab.
- **R** — für Zahlen und Diagramme.
- **Julia** — für Rechnen und Wissenschaft.
- **Scratch** — Bausteine statt Tippen.
- **FASM** — Assembler. Du kennst es aus Lektion 8.
- **Zig** — ein neuer Ersatz für C.
- **TypeScript** — JavaScript mit Typen.
- **Dart** — für Apps mit Flutter.
- **Lisp** — alte Sprache mit Klammern.
- **Prolog** — Regeln statt Anweisungen.
- **Haskell** — reines Rechnen mit Funktionen.
- **Erlang** — viele Aufgaben gleichzeitig.
- **Elixir** — modern, auf Erlang gebaut.
- **COBOL** — alte Sprache für Banken.
- **Fortran** — alte Sprache für Physik.
- **Perl** — alt, gut für Text.

## Was du zuerst lernst

Bleib bei dem, was du schon kannst.
JavaScript reicht für den Anfang.
Python ist ein guter zweiter Schritt.
C zeigt dir, wie ein Computer denkt.
Später kannst du wählen, was du brauchst.

## Deine Übung

Nimm drei Sprachen aus der Liste.
Schreib dazu je einen Satz:
„Ich höre von … und würde damit … machen."

## Eine Frage an den Agenten

„Welche Sprache passt zu meinem kleinen Spiel?"
