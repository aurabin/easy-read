# Lektion 13 — Python

## Die Idee

Python ist kurz.
Du schreibst weniger Zeichen als in JavaScript.
Darum lernen viele damit zuerst.

## Ein Beispiel

```python
name = "Jorge"
for x in range(4):
    print("Hallo " + name)
```

## Die Schritte

1. Öffne einen Python-Editor oder eine Konsole.
2. Schreibe das Beispiel.
3. Starte es.

## Das solltest du sehen

Viermal „Hallo Jorge".
Jede Zeile ist neu.

## Wenn es nicht geht

- Nichts passiert? Prüfe die Leerzeichen nach `for`.
- Ein Fehler bei `print`? Prüfe die Klammern.

## Wörter

- **Konsole** — ein Fenster für Textbefehle.
- **Einrückung** — Leerzeichen am Zeilenanfang. Sie gehören zur Regel.

## Deine Übung

Mach die 4 in der dritten Zeile größer.
Lass den Namen weg.
Schreib stattdessen deinen eigenen.

## Eine Frage an den Agenten

„Warum stehen die vier Leerzeichen bei `print`?"
