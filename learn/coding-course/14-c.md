# Lektion 14 — C

## Die Idee

C ist alt und immer noch da.
Es liegt nah an der Maschine.
Dein Chip-Kurs nutzt diese Welt.
Auch Web Assembly ist davon inspiriert.

## Ein Beispiel

```c
#include <stdio.h>
int main(void){
  int x;
  for(x=0; x<4; x=x+1){
    printf("Hallo %d\n", x);
  }
  return 0;
}
```

## Die Schritte

1. Öffne einen C-Editor.
2. Schreibe das Beispiel.
3. Übersetze es mit `gcc hello.c -o hello`.
4. Starte es mit `./hello`.

## Das solltest du sehen

Vier Zeilen.
Jede zeigt eine Zahl.
Sie läuft von 0 bis 3.

## Wenn es nicht geht

- Der Befehl `gcc` fehlt? Dann ist kein C-Werkzeug installiert.
- Ein Fehler bei `printf`? Prüfe die Anführungszeichen.

## Wörter

- **Übersetzen** — aus Quelltext ein lauffähiges Programm machen.
- **Variable** — hier `x`. Sie hält eine Zahl.

## Deine Übung

Ändere die 4 in eine 8.
Lass die Zahl in der Ausgabe weg.
