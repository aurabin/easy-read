# Lektion 21 — Alle Oberflächen

## Die Idee

Jeder Computer hat eine Oberfläche.
Manche zeigen Fenster.
Manche zeigen nur Text.
Manche zeigen Symbole auf einem Telefon.
Alle lösen dieselbe Aufgabe:
Du sagst, was der Computer tun soll.

## Die Gruppen

| Gruppe | Beispiele | Wie man sie bedient |
| --- | --- | --- |
| Große Systeme | Windows, macOS, Linux | Maus, Tastatur, Fenster |
| Oberflächen von Linux | GNOME, KDE, XFCE | Schubladen und Arbeitsflächen |
| Amiga-Familie | AmigaOS, MorphOS, AROS | Workbench, rechts klicken |
| Andere alte Systeme | KolibriOS, Haiku, RISC OS | Fenster, oft klein und schnell |
| Textsysteme | MS-DOS, Shell, AmigaShell | Befehle tippen |
| Telefone | Android, iOS | Finger wischen und tippen |
| Im Browser | Webseiten, Web-Apps | Klicken und scrollen |
| Spiele | Konsole, Oberfläche im Spiel | Knöpfe und Steuerkreuz |
| Eingebettet | Auto, Kühlschrank, Router | few Knöpfe, kleines Display |

## Was alle gemeinsam haben

- Sie zeigen einen Zustand.
- Sie warten auf eine Eingabe.
- Sie geben eine Antwort.
- Sie haben Regeln für Reihenfolge und Nähe.

Das ist der Kern aus Lektion 7.
Schleife. Eingabe. Regel. Ausgabe.

## Zwei große Arten

Die eine Art ist die Textzeile.
Du tippe `ls` oder `dir`.
Der Computer antwortet mit Text.
Das ist schnell und genau.

Die andere Art ist das Bild.
Du klickst ein Symbol an.
Ein Fenster geht auf.
Das ist gut für den ersten Schritt.

Die besten Systeme haben beides.
AmigaOS hat Shell und Workbench.
Linux hat Konsole und Desktop.

## Beispiele aus unserem Projekt

- `site/index.html` — Workbench von OS 4.1.
- `boing-ball.html` — eine kleine Fläche mit Kugel.
- Die Datei für das Feld — ein Feld mit Reglern.
- KolibriOS — echte Fenster im Mini-Format.
- `ALL-IN-ONE.html` — ein Fenster, eine Dock-Leiste.

## Deine Übung

Nimm deinen Computer.
Suche die Oberfläche.
Finde drei Dinge:
ein Fenster, ein Menü, eine Antwort nach deinem Klick.
