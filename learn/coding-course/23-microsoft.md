# Lektion 23 — Microsoft

## Die Idee

Microsoft ist mehr als Windows.
Die Firma begann mit einer Sprache für einen kleinen Computer.
Heute steht sie für Cloud, Spiele und KI.
Das ist eine lange Geschichte mit Wendungen.

## Die Anfänge

Gates und Allen sahen 1975 den Altair 8800.
Sie schrieben BASIC dafür.
Der Name Microsoft kam von Micro und Software.
1979 zog die Firma nach Washington.

Der Große Auftrag kam 1980 von IBM.
Microsoft kaufte QDOS und nannte es MS-DOS.
Der IBM PC kam 1981.
Andere Firmen bauten ihn nach.
Alle brauchten DOS.
So wuchs das Geschäft.

## Die Kämpfe

Windows kam 1985.
Es lief erst auf DOS.
Mit Windows 3.0 im Jahr 1990 kam der Durchbruch.
Apple klagte 1988 wegen der Oberfläche.
Die USA klagten 1998 wegen Marktmacht.
2001 gab es einen Vergleich.
In Europa folgten weitere Verfahren.

Viele haben das kritisiert.
Andere sagen: Microsoft hat Standards gesetzt.
Beides kann man sagen.

## Der Wandel

2000 gab Gates den Chefposten ab.
Steve Ballmer übernahm.
2014 kam Satya Nadella.
Er setzte auf Cloud und offene Werkzeuge.

2016 kaufte Microsoft LinkedIn.
2018 kam GitHub dazu.
Die Firma, die früher offene Software ablehnte,
wurde zu einem ihrer größten Förderer.

2023 kam die KI-Wende.
Microsoft investierte in OpenAI.
Copilot zog in viele Programme ein.

## Kritik

Es gibt auch Kritik:
an Marktmacht, an Sicherheit,
an Werbung in Produkten, an Stellenabbau.
Ich nenne das hier nur.
Ich bewerte es nicht.

## Was wir lernen

Eine Firma kann sich wandeln.
Aus BASIC wurde DOS.
Aus DOS wurde Windows.
Aus Windows wurde Cloud und KI.

Unser Projekt ist klein daneben.
Aber es zeigt denselben Weg:
erste Zeile, erstes Fenster, nächster Schritt.
