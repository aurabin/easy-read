# Lektion 26 — Kannst du AROS mitbauen?

## Die Idee

Ja. Du kannst AROS mitbauen.
Du musst kein Profi sein.

## Was du brauchst

- Einen Computer. Linux ist am einfachsten.
- Git, um den Code zu holen.
- Ein paar Bauwerkzeuge. Zum Beispiel GCC und make.
- Zeit und Neugier.

Du musst nicht schon alles können.

## Zwei Wege

Du kannst den Code kopieren und ändern.
Das heißt: ein Fork.
Dafür brauchst du keine Erlaubnis.
Willst du den Hauptcode ändern, fragst du das Team.
Du schickst erst kleine Änderungen.
Dann kannst du mitmachen.
Quelle: GitHub, Datei `CONTRIBUTING.md`.

## Wie du helfen kannst

Du musst keinen Code schreiben.
Du kannst auch:

- eine Bauart testen und Fehler melden
- Texte in deine Sprache übersetzen
- die Hilfe verbessern
- einen kleinen Fehler beheben
- ein Programm zu AROS bringen

## Die Schritte

1. Baue AROS auf deinem Rechner. Siehe Lektion 25.
2. Mach eine kleine Änderung.
3. Mach deine eigene Kopie vom Code.
4. Schick einen Pull Request.
5. Frag in der Mailingliste.

Das Team will bei großen Änderungen vorher reden.
Kleine Änderungen dürfen direkt kommen.
Halte dich an die Regeln.
Quelle: GitHub, Datei `CONTRIBUTING.md`.

## Ein Beispiel

Du findest ein falsches Wort im Menü.
Du änderst eine Zeile.
Du schickst einen Pull Request.
Jemand prüft ihn und sagt ja.
Das ist echte Hilfe.

## Probier es (etwa 5 Minuten)

1. Öffne die AROS-Seite auf GitHub.
2. Such die Datei `CONTRIBUTING.md`.
3. Lies den ersten Abschnitt.
4. Schreib auf, wie du helfen könntest.

## Ehrlich

Ich habe AROS nicht selbst gebaut.
Ich habe auch noch keine Änderung geschickt.
Ich habe die offiziellen Seiten gelesen.
Nicht mit echten Nutzern getestet.
