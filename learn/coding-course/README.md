# Coding-Kurs — Schritt für Schritt

## Willkommen

Das ist ein richtiger Kurs.
Du lernst, indem du kleine Dinge baust.
Jede Lektion hat ein Ziel.
Jede Lektion hat eine Übung von fünf Minuten.

**0+ heißt: Du brauchst kein Vorwissen.**

Der Kurs ist nicht für Kinder gedacht.

Der Witz steht am Anfang.
Er ist von ``learn/joke.md``.

„Mir reichts! Ich geh schaukeln!
Meine Freunde gehen rutschen!"

## So arbeitest du

1. Lies eine Lektion.
2. Mach die Schritte.
3. Lies „Das solltest du sehen".
4. Geht es nicht? Lies „Wenn es nicht geht".
5. Mach die Übung.
6. Frag den Agenten eine Frage.

Du kannst jederzeit aufhören.
Eine Lektion zählt schon.
