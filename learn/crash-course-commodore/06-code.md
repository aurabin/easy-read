# Lektion 6 — Code auf dem C64

## Du bist dran

Der C64 spricht BASIC.
Das ist eine einfache Sprache.
Du schreibst Zeilen mit Nummern.
Der Computer liest sie der Reihe nach.

## Deine erste Zeile

```basic
10 PRINT "HALLO"
```

Zehn ist die Nummer.
PRINT heißt: Schreib das.
HALLO ist der Text.

## Zeilen hinzufügen

```basic
10 PRINT "HALLO"
20 PRINT "WIE GEHT'S?"
```

Drück RUNSTOP und RETURN.
Beide Zeilen erscheinen.

## Eine Schleife

```basic
10 PRINT "ICH BIN DA"
20 GOTO 10
```

GOTO heißt: Geh zurück zu Zeile 10.
Der Text kommt immer wieder.
Drück RUNSTOP und STOP, wenn es reicht.

## Mach das

Ändere den Text.
Nimm deinen Namen.
Mach drei Zeilen.
