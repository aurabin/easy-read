# Lektion 3 — Dein erster Code

## Was brauchst du?

Nur einen Browser.
Den hast du schon.
Kein Kauf. Kein Programm installieren.

## Schritt für Schritt

1. Öffne eine leere Seite.
2. Schreib diese Zeile:

```html
<h1>Hallo Welt!</h1>
```

3. Speichere die Datei als `hallo.html`.
4. Öffne sie mit einem Doppelklick.

Du hast gerade Code geschrieben.
Der Browser zeigt ihn dir.

## Was ist passiert?

Das Zeichen `<h1>` sagt:
Das hier ist eine große Überschrift.
Das Zeichen `</h1>` sagt:
Hier hört sie auf.

Zwei Zeichen. Eine Idee.

## Mach es bunter

Probier das:

```html
<h1 style="color:red">Hallo Welt!</h1>
```

Jetzt ist der Text rot.
Du hast Farben benutzt.

## Mach das

Ändere die Farbe.
Nimm blau oder grün.
Schreib deinen Namen statt Hallo Welt.

Er springt.
