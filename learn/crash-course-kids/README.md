# Computer Crash Course für Kids

Kurzer Kurs. Großer Spaß.
Du brauchst kein Vorwissen.
Du brauchst keinen teuren Computer.
Alles ist kostenlos und offen.

| Nr. | Lektion | Was du lernst |

## So lernst du

- Eine Lektion pro Tag reicht.
- Lies kurz. Mach dann die kleine Aufgabe.
- Frag eine erwachsene Person, wenn du willst.
- Kein Video. Kein Anruf. Alles geht schriftlich.

## Ehrlich

Der Kurs ist nicht mit echten Kids getestet.
Das sagen wir offen.
