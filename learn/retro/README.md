# Retro computing: a short course

Two machines, in order.

## First, a joke

„Mir reichts! Ich geh schaukeln! Meine Freunde gehen rutschen!“

“I’ve had enough! I’m off to the swings! My friends are off to the slide!”

The pun is German. All six languages are in [`../joke.md`](../joke.md).

1. **Commodore 64** — start here. It is simple, free to emulate, and you can
   type a program in one minute.
2. **Amiga** — come second. It has a desktop, a mouse, and more to set up.

## Before you start

- **0+:** if you have never used a computer, do the four `../start-here/`
  lessons first. They take about 20 minutes.
- You do not need old hardware. An emulator is a program that acts like the
  old machine.
- You do not need to buy anything. Both emulators are free.
- The Amiga emulator needs a Kickstart ROM file. It is not free. See lesson 2.
- Lessons take 10 to 20 minutes each.
- You can stop after any lesson.

## How to use a lesson

- Read one lesson. Do the steps.
- If a step fails, read "If it does not work".
- Ask the agent one question at a time.
- Say "explain step 3 again" when a step is unclear.
