# Lesson 2: Install the emulator

**Time:** 20 minutes. **You need:** a Windows, Mac, or Linux computer.

We use **FS-UAE**. It is free and open source.
It runs on Windows, Mac, and Linux.

## The ROM problem

An Amiga needs a **Kickstart ROM** to start.
The ROM is copyrighted. It is not free.

You have three honest choices:

1. **Buy Amiga Forever.** It comes from Cloanto. It includes licensed ROMs.
2. **Use free AROS.** AROS is a free replacement. Not every game runs on it.
3. **Use a ROM you already own.** Do not download one from a random site.

This lesson uses choice 1. It is the simplest.
Prices change. Check the website before you pay.

## Steps

1. Open https://fs-uae.net/ in your browser.
2. Download the version for your system.
3. Install it, or unzip it. Do not run it from inside the zip.
4. Open **FS-UAE Launcher**.
5. If you bought Amiga Forever, find its ROM folder.
6. In the Launcher, open **Preferences**.
7. Add the Kickstart ROM folder.
8. Go back to the main window.
9. Choose **Amiga model: A500**.
10. Choose **Kickstart 1.3**.
11. Click **Start**.

## What you should see

- A grey or black screen for a moment.
- Then a picture of a hand holding a floppy disk.

That is the insert-disk screen.
It means the Amiga started.
It has no disk yet. Lesson 3 adds one.

## If it does not work

- **It asks for a ROM:** set the ROM folder in Preferences.
- **The screen stays black:** check the model and the Kickstart version.
- **It crashes at once:** try Kickstart 1.3 with the A500. Not 3.1.
- **FS-UAE will not start:** try WinUAE on Windows. It is also free.

## Try this

1. Start the emulator once. Look at the screen.
2. Find the FS-UAE menu key. It is often **F12**.
3. Open the menu. Change nothing. Close it.
