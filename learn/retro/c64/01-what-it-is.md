## Short answer

The Commodore 64 is a home computer from 1982.
It was cheap, and it sold in millions.

## What is inside

- **CPU:** MOS 6510. It runs at about 1 MHz. That is very slow today.
- **RAM:** 64 KB. The name "64" comes from this.
- **Graphics:** the VIC-II chip. 16 colours. 40 columns of text.
- **Sound:** the SID chip. 3 voices.
- **BASIC:** a programming language built in. It starts when you turn on.

## Why people still use it

- You can learn programming on it. It is small enough to understand.
- Musicians still write music for the SID chip.
- The demoscene makes art and sound with it.
- Many games are still fun.

## Words you will meet

- **Emulator:** a program that pretends to be a C64. It runs on your PC.
- **ROM:** fixed code that starts the machine. The emulator includes it.
- **Disk image:** one file that acts like an old floppy disk.
- **BASIC:** the language you type on the C64.

## One fact to remember

The C64 does not start a desktop.
It starts a text screen with a cursor.
You type a command, and it answers.
