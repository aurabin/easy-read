# Lesson 3: What is a program?

**Time:** 10 minutes. **You need:** nothing.

## Short answer

A program is a list of instructions.
The computer does them in order.

## An everyday example

Making tea:

1. Fill the kettle.
2. Boil the water.
3. Put a tea bag in a cup.
4. Pour the water into the cup.
5. Wait 3 minutes.

The order matters.
If you pour first, the tea is cold.

## Two useful ideas

- **Loop:** do the same step again. Like stirring 5 times.
- **Choice:** do one thing or another. Like "if it rains, take an umbrella".

## A bug

A bug is a mistake in the instructions.
The computer does exactly what you wrote.
It does not do what you meant.

## Try this

Write 5 steps for brushing your teeth.
Number them.
Read them in order.
Is any step in the wrong place?
