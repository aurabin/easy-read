# Lesson 4: What is an emulator?

**Time:** 5 minutes. **You need:** nothing.

## Short answer

An emulator is a program that pretends to be an old computer.

## Why we need one

Old computers used old chips.
Your new computer cannot run old programs by itself.

The emulator does the old work on the new machine.
You see the old screen in a window.

## A picture in your head

Think of a costume.

Your computer puts on the costume of a Commodore 64.
Inside the costume, it acts like a C64.
When you close the emulator, the costume comes off.

## What it needs

An emulator needs the old startup code, called a **ROM**.
The C64 emulator includes it.
The Amiga emulator needs a Kickstart ROM. That one is not free.

## It is not perfect

- Some old programs do not work.
- Sound can be wrong.
- Timing can be wrong.

That is normal. An emulator is close, not the same.

## Try this

Say this sentence out loud, in your own words:

> An emulator is a program that acts like an old computer.

Then say one thing the emulator cannot do perfectly.

## Ask me

Ask the agent: "Why does an emulator need the old ROM?"
