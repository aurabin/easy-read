AROS selbst gebaut

Ich habe AROS aus dem Quelltext gebaut.

Das ist kein fertiger Download.

Das ist auch keine Nachbildung.

Was ich benutzt habe

  • Den Quelltext vom AROS-Projekt.
  • Den Stand 5d55abdc.
  • WSL mit Ubuntu 22.04 auf diesem Rechner.
  • Das Ziel pc-x86_64. Das heißt 64 Bit x86.

So habe ich gebaut

Zuerst habe ich die Kataloge aus dem Quelltext geholt.

git submodule update --init --recursive

Dann habe ich AROS eingestellt.

../AROS/configure --target=pc-x86_64 --enable-ccache --enable-build-type=nightly

Dann habe ich AROS gebaut.

make -j16

Zum Schluss habe ich die CD gebaut.

make -j16 bootiso

Das Abbild

  • ISO: aros-pc-x86_64.iso
  • Größe: 723.238.912 Bytes
  • Die ISO heißt im Innern „AROS Live CD".
  • Systemkennung: AROS-X86_64-PC
  • Sie ist eine ISO-9660-CD mit El Torito für x86.

Herkunft und Lizenz

AROS kommt vom AROS-Projekt.

Die Lizenz heißt AROS Public License, kurz APL.

Starten

Die ISO läuft nicht im Browser. Du brauchst QEMU.

Starte die ISO mit diesem Befehl:

qemu-system-x86_64 -accel tcg -m 2048 -cdrom "aros-pc-x86_64.iso" -boot d

Auf diesem Rechner ist QEMU installiert unter

C:\Users\icaro\Tools\QEMU\qemu-system-x86_64.exe
