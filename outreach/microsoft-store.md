## Kurze Beschreibung

Ein kostenloser Lernkurs in klarer Sprache. Von der ersten Codezeile bis zu AROS. Mit viel Geschichte über Microsoft.

## Lange Beschreibung

Dieser Kurs erklärt Programmieren in kurzen Sätzen.

Er beginnt mit einer einfachen Seite.
Dann kommen Farben, JavaScript und ein Bildfeld.
Dann Bewegung, Spiele und Oberflächen.
Dann Assembler und Web Assembly.
Dann Linux, AROS, MorphOS und AmigaOS 4.1.

Besonders ausführlich ist die Geschichte von Microsoft:

- 1975 gründen Bill Gates und Paul Allen Microsoft.
  Das erste Produkt ist Altair BASIC.
- 1981 liefert MS-DOS die Basis für den IBM PC.
- 1985 erscheint Windows 1.0.
- 1990 wird Windows 3.0 zum Erfolg.
- 1995 bringt Windows 95 das Start-Menü.
- 2008 beginnt mit Azure die Cloud-Zeit.
- 2014 wird Satya Nadella Chef.
- 2018 kauft Microsoft GitHub für 7,5 Milliarden Dollar.
- 2023 folgt die große KI-Wende mit Copilot.
- 2026 kommen eigene Chips: Maia und Cobalt.

Die Geschichte zeigt: Aus einer kleinen Idee wurde eine Plattform.
Der Kurs erzählt das in Easy Read.
