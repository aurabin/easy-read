## Descriptive use of historical names

"Commodore 64", "Amiga", and model names are used to describe real machines.
We do not use official logos. Add this disclaimer anywhere you share the work:

> An independent educational project. Not affiliated with, endorsed by, or
> sponsored by Commodore, Amiga, or any rights-holder. Names are used only to
> describe historical machines.

## The Amiga system — open by default

- The default system is open (AROS-style). AROS is a free, open-source
  Amiga-compatible operating system. Link: https://www.aros.org
- WinUAE is a free emulator; our config panel mirrors its options.
  Link: https://www.winuae.net
- Real Kickstart ROMs and Workbench are **copyrighted and not included**.
- The requester can register a file *you own*, by name only. Nothing is
  uploaded or stored except the name on your own device.
- To run real ROMs, use a real emulator and your own legally acquired files.

## Virtual hard disks
- A500: 50 MB. Other models: 2 GB. A4000/A4000T: variable up to 40 GB.
- These are simulated. Only names and sizes are stored. No real disk space is
  used, and no copyrighted disk images are bundled.

## Administrator rights for everybody
In the virtual fields and the Workbench, every visitor is an administrator.
There is no login and no permission gate. This is a simulation; it grants no
rights on a real computer.
